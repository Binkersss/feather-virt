# Contributing to Feather Virt

Thank you for your interest in contributing! Your help makes this project better for everyone.

## How to Contribute

1. **Report Issues:** Use GitHub Issues to report bugs, request features, or ask questions. Include as much detail as possible.
2. **Fork & Branch:** Fork the repository and create a descriptive branch for your work:

   ```bash
   git checkout -b feature/my-feature
   ```
3. **Write Code:** Follow existing code style and project conventions. Include comments and keep changes focused.
4. **Testing:** Add unit and integration tests where appropriate. Ensure all tests pass locally before submitting.
5. **Pull Requests:** Open a pull request (PR) with a clear description of your changes. Reference any related issues using `#issue_number`.

## Code Style

* Follow the C99/C11 standards for C code.
* Use clear, descriptive names for functions and variables.
* Keep functions concise and modular.
