# Code of Conduct

We value a welcoming and respectful community. All contributors, maintainers, and users are expected to uphold this code of conduct.

## Our Standards

* Be respectful, considerate, and professional.
* Avoid harassment, discrimination, or offensive language.
* Assume good intentions and provide constructive feedback.
* Respect others’ time and contributions.

## Reporting Issues

If you experience or witness unacceptable behavior, please report it by contacting:
**[nathaniel.chappelle@proton.me](mailto:nathaniel.chappelle@proton.me)**

## Enforcement

Anyone violating this code of conduct may be warned, temporarily blocked, or permanently banned from contributing, depending on the severity of the incident.

We want this project to be inclusive, safe, and productive for everyone.
